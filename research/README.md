The run contract separates three identities:

| Record | Contents | Change policy |
|---|---|---|
| Recipe snapshot | Recipe and shared/production source, resolved config, dependency locks, source hashes | Content-addressed; any changed input creates a new snapshot |
| Experiment specification | Snapshot ID, seeds, board/rules/komi, training/replay lineage, data and opponent hashes, primary metric, stopping/budget rules, planned comparisons | Frozen before the experiment; amendments create a new specification |
| Execution attempt | Experiment ID, host/rank map, runtime and binary versions, timestamps, checkpoints, counters, failures, costs, result hashes | New attempt on restart; append records and link the parent checkpoint |

The source snapshotter currently captures the selected recipe, `packages`, `crates`, `production`, `eval`, `ops`, `tests`, and declared root files. It includes common source/config/document extensions and excludes caches/build products/hidden files. Additional source formats must be added explicitly; binary models and datasets belong in external manifests with hashes. It rejects source symlinks and requires `uv.lock`; Rust source also requires `Cargo.lock`. It works without Git, which matters in the present workspace. When Git becomes available, record its commit/dirty state as additional provenance, not as a substitute for the exact bundle.

The pod executor verifies a bundle, materializes its locked Python environment, and runs that bundle's trainer and shared library. Running live source while recording an old snapshot ID is forbidden by the experiment contract. Every SPMD host attests the same source/config identity before distributed initialization. Host manifests capture Python, JAX/jaxlib/libtpu, topology, and the explicit launch environment. External native builds and weights require separate hash receipts. Do not snapshot arbitrary environment variables or credentials.

All scientific settings are resolved before execution. CLI options select a configuration, seed, attempt directory, and operational overrides whose permitted scope is recorded. A stop/resume operation preserves the original learning-rate horizon, sample accounting, RNG state, and replay cursor. Checkpoints contain full learning state and completed manifests; starting a new research branch from a checkpoint creates explicit lineage and charges its pretraining compute. Multi-host asynchronous runs target reproducible procedures and statistical results; bitwise replay is a separately tested property, not an assumption.

Each study freezes its primary outcome, compute allowance, seed plan, held-out openings, and promotion criterion before screening. Shared-parent forks are useful for screening; finalists require independent initialization. Record unsuccessful trials, compilation, padding, speculative waste, evaluator cost, data age/reuse, and idle reserved capacity. Report both equal-search-budget and equal-total-time results where they answer different questions. The broad design's total budget is authoritative.

Validation progresses through rules/reference parity, model/update/checkpoint checks, search/trace-resolver checks, real pipeline profiling, repeatable small-board learning, and held-out real KataGo matches. Neural loss or a toy opponent does not satisfy the external benchmark gate. The benchmark runner must use official KataGo search, pinned executable/config/weights, controlled budgets, paired colors/openings, authoritative rules, timeout/crash accounting, SGFs, and uncertainty estimates. Its implementation and actual matches remain required before promoting a learned method. See [eval/README.md](../eval/README.md).

Promotion copies the reviewed recipe into `production/recipes/<name>` with its source snapshot and validation lineage. The production entrypoint uses that version, with bounded documented schedules and recovery behavior. It does not discover a changing "best" research directory at runtime. Correctness and recovery checks rerun on the production packaging before committing the long training allocation.
