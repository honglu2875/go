# Separate the expert's state representation from observed-opponent learning

The registered BCE2 prediction criterion failed: outcome MSE increased from 0.812813 to 0.829740. All 144 prescheduled external games also completed; the score-interval and completion criteria failed. The same architecture and examples therefore do not support replacing MSE with this loss at the tested budget. Preserve both negative results. Do not choose another multiplier or checkpoint using these outcomes and describe it as the original experiment.

The next architecture experiment should test an expert organized around spatial state features. The current expert combines a causal move-history transformer with a small convolutional board encoder. The behavior head reads stopped-gradient features from those expert-trained encoders. Separate heads prevent direct behavior gradients from changing expert parameters, but the common gradient norm still changes the expert update scale. They also do not let the history encoder learn representations specifically for observed-opponent prediction.

Use an explicit state expert and an independently trained causal behavior model as a candidate. The state expert predicts search-policy targets and side-to-move outcomes. Its inputs include exact relative stones, side to move, komi, legal-action information and previous-pass context; the Rust engine remains authoritative for legality, repetition and terminal scoring. A current board tensor is not a complete Markov state under positional superko. The behavior model conditions on actual past moves and declared opponent context, with observed next-action NLL as its objective. Hypothetical branches must never update the real opponent context.

This is two changes: spatial expert representation and behavior-specific representation/optimizer ownership. Isolate them. First compare the current history-conditioned expert with a spatial expert while keeping the behavior adapter and clipping convention fixed. Report active expert parameters, total parameters, inference FLOPs, measured update time and total training cost separately; merely retaining unused history parameters is not parameter matching. Then, only if the representation comparison is useful, clone it to give behavior its own encoder, optimizer moments and gradient clipping. Include a counterfactual test that changing behavior labels leaves the full expert update unchanged; zero direct gradients alone is insufficient.

Before training, qualification must cover spatial symmetry, exact feature reconstruction from native games with captures/passes/ko, causal behavior inputs, policy/value masks, independent objective gradients and fresh-process continuation. Keep board sizes as explicit compiled buckets. Test the state expert on 9x9 first and report 19x19 as unqualified until measured. An expert that no longer consumes history also needs a new evaluation adapter and separate speculative-execution qualification; the existing causal adapter must not silently reinterpret its inputs.

Freeze one control and one candidate, initialization seeds, exact data exposures, validation metrics, fixed checkpoint and fresh paired KataGo openings before either full run. Preserve the current MSE control unless a separate registered loss comparison justifies changing it. Evaluate policy approximation, illegal prior mass, phase-stratified outcome calibration and observed-behavior NLL; use external game score and completion to decide whether to replicate. Offline distillation can qualify approximation and infrastructure, but the eventual sample-efficiency claim requires independent RL self-play runs with total teacher/pretraining cost included.

Independent production work remains necessary: explicit actor/inference/learner ownership, bounded queues and model publication, durable replay and complete checkpoints outside this pod, and actual host-loss/partition recovery. The fixed-policy speculative speed measurements cannot substitute for integration into MCTS or a sustained learning run.
