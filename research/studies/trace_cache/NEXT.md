Attention should read the shared committed history plus branch-local deltas, avoiding a full 329-token KV copy for every branch. After native resolution, gather only the accepted branch's deltas through the last validated policy input; append the actual final move separately. That move can differ from both the returned proposal and an already-computed hypothetical future. Retain exact model/context, episode, generation, prefix and inactive/reset rules. Compare every emitted control and certificate with the existing Python reference, including stale masks/tickets, heterogeneous acceptance, captures, corrected final moves and terminal/cap resets.
