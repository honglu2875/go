Reviewed 2026-09-13. This is a literature recommendation, not an experiment registration. Primary papers and original institutional publications were prioritized; all FAIR references below predate 2024. PaliGemma is a separately identified 2024 Google DeepMind reference.

The recommended direction is a residual convolutional board encoder, spatial interaction among the known board tokens, and eventually learned compression of the tokens retained in game history. These are hypotheses for our Go study, not conclusions established by image benchmarks.

Our current comparison uses 36 overlapping soft tokens per 9x9 board, a width-768 causal decoder, one supervised policy objective, and about 233M total parameters. The six-layer C768 encoder is a plain convolution stack without residual connections. Its final validation KL was 0.511634 versus 0.521731 for C128 and 0.420361 for the CNN reference. The encoder and decoder allocation changed together, so the improvement cannot isolate encoder width or depth. These are single-seed results on fixed weak-teacher data. The new large-encoder checkpoint arrays were lost from temporary storage; the result records and frozen recipe remain. [Local comparison and recovery record](encoder_overnight_handoff_20260913_v2.md).

The closest causal-decoder reference is [PaliGemma](https://arxiv.org/html/2407.07726v2), Google DeepMind, 2024. It starts from pretrained vision and language models, then jointly updates the whole model during multimodal pretraining. Its prefix mask allows bidirectional attention over known input tokens and causal attention over generated output; Section 5.2 finds this better than making the input causal too. Our proposed repeated board-block mask is an adaptation: every patch in observation t can attend to that observation and prior history, but cannot see action t or later observations. This does not require predicting future board patches. It motivates a controlled mask ablation, not a claim about Go performance or learning from random initialization.

Two additional references inform implementation choices. [ConvNeXt](https://arxiv.org/abs/2201.03545), FAIR / UC Berkeley, CVPR 2022, supplies residual convolution blocks with LayerNorm and pointwise channel mixing. It is a pure CNN paper; inserting those blocks into our jointly trained hybrid would be our experiment. [EfficientViT: Memory Efficient Vision Transformer With Cascaded Group Attention](https://www.microsoft.com/en-us/research/uploads/prod/2023/06/EfficientViT.pdf), Microsoft Research / CUHK, CVPR 2023, studies attention-related memory overhead and attention/FFN allocation. This is a different paper from MIT's EfficientViT. Its layout ideas warrant later decoder profiling, not an assumed TPU speedup.

The proposed sequential experiments are:

1. Finish the already prepared spatial policy-correction qualification and learning ablation. This gives evidence about whether the global policy readout discards useful board-location information. Its prior interruption occurred before any learning update.
2. Test bidirectional interaction within the current observation, retaining causal game history and the same policy objective. Keep shapes fixed for the mechanistic comparison and report the additional attention work. Require a separately budget-matched comparison before claiming an equal-FLOP improvement. The prepared board-mask option has CPU qualification, not a completed TPU learning result.
3. Establish a residual encoder. First separate normalization and residual-connection effects where shapes can be held fixed. Then investigate a gradually widening stem, for example channel stages 128, 256, and 512 followed by projection to decoder width 768. Keep stride 1 and the existing 36-token interface initially. Exact block counts and decoder allocation must come from the joint parameter/FLOP solver, not this illustrative channel schedule.
4. On the strongest qualified encoder, compare learned token compression against the fixed-patch interface. Start with 16 tokens before trying 8. Preserve 2D location information in the spatial feature path, and combine it with historical context for move logits; retain a pass output and one policy distribution. A two-way Mobile-Former-style bridge is a subsequent comparison if simpler pooling is promising.
5. Only then test more invasive spatial attention or decoder efficiency changes. A depthwise convolution's low arithmetic cost can coexist with poor accelerator utilization. Profile dense or fused bottlenecks as alternatives before choosing a production implementation.

Every main learnability comparison should use the same fixed games, position exposures, validation split, decoder width 768, and single policy target. Keep total parameters near 233M and count the entire encoder, tokenizer/resampler, attention, FFN, and policy output in the decoding budget. Match at the existing 9x9, batch-128, 128-past-move reference and report sensitivity to other history lengths; one reference match does not imply matching everywhere. Separately report training work including rematerialization, padded execution work, cached decoding latency, memory use, and utilization measured on the TPU.

Token compression changes how much parameter reuse occurs at each move, so matching both parameters and decoding FLOPs requires an explicit allocation search. An unmatched cheaper model can still be useful, but its result belongs on a quality/latency comparison rather than being called equal-FLOP. Give each architecture a comparable narrow learning-rate search and confirm a selected improvement with another seed before a large expansion. Preserve frozen recipes and write persistent checkpoints at each run boundary. These experiments address supervised learnability; real KataGo matches and subsequent reinforcement-learning experiments are required to establish playing strength and faster improvement.
