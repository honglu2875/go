# Complete-state self-play continuation

This clone owns the qualified Gumbel attention/CNN model and full online trainer. `gozero.checkpoint_forks` adds a distinct initialization path for a new frozen run. Ordinary resume still requires the exact child snapshot, configuration, native binary and initialization identity.

A fork descriptor pins every parent rank's committed checkpoint, the parent source/config/group, exact model code, native receipt/binary, dependency lock, Python version, topology and expected schedule changes. It retains parameters, SGD momentum, augmentation and replay-sampling RNGs, replay contents/cursor, complete native actors and all counters. Parent files are read and hash-verified; they are never rewritten to carry a child identity. Each subsequent child checkpoint records the fork origin and phase counters separately from cumulative counters.

The first version permits only a new stop turn, checkpoint/log cadence, and an explicitly declared constant learning-rate override. It rejects changes to model architecture/code, search, rules, replay shape, batch size, seeds, worker placement or topology. The exact parent native binary remains an explicit dependency, rather than receiving a new build identity. A normal child resume does not need the old replay arrays, but retains the small source/descriptor/native dependencies needed to verify its provenance.

The online learning loop and model update are unchanged. Exact CPU and multi-host continuation are qualified, including every subsequent game and full replay/actor state. Recorded-history GTP and single-thread real-KataGo equivalence also passed; the failed earlier multithreaded exact-game check is retained. See `research/studies/continued_selfplay` for evidence and `research/studies/online_annealing` for the bounded first extension. This is continuation infrastructure, with no algorithmic improvement or production promotion established. External durability, network-partition/host-loss recovery and larger production schedules remain separate requirements.
