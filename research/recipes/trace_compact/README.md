# Shared history and branch-delta KV experiment

This complete clone of `trace_cache` keeps the trained model, full-prefix decoder and Python cache coordinator unchanged. `dense_decode.py` is the exact preceding dense-cache implementation. Nine modes compare full-prefix, dense retained and compact retained execution for sequential, learned-behavior k=4 and known-policy joint k=1 traces. No model is trained.

The compact carry has one committed KV history per game, short branch-local KV deltas and observed-move counts. On the next dispatch it gathers only the selected branch deltas strictly before the final accepted action, commits those to the shared history, and appends the actual final action. Both policy views read the shared history during attention; hypothetical appends write only the short deltas. Root token KV is shared. Finite stale slots outside the validated prefix are masked. Inactive game carries remain unchanged; episode resets clear history. Python metadata ownership, complete prefix guards and native board transitions remain the same as the dense control.

Attention uses a joint softmax over committed-history and delta score blocks and adds their value reductions. This changes floating-point evaluation order. CPU numerical checks and exact real-device event/state qualification precede any speed claim. Tests cover heterogeneous long histories, masked junk, branch KV versus independent full-prefix reconstruction, captures, legality-corrected final actions, terminal/cap resets, inactive rows, model/generation changes and fresh-process reconstruction. Cold reconstruction is not full distributed checkpoint recovery.

All nine modes consume the same registered work and must match sequential native events and final states. Four timing orders balance compact/dense and compact/full-prefix precedence. Required cache guards, carry drain, frame creation, dispatch, host transfers and native resolution are inside measured loops. Initial immutable carries are allocated during compilation/warmup; buffers are not donated. Retained carry bytes are logical device tensors, not measured HBM traffic. Compiler FLOPs and timeline occupancy do not establish MFU.

The parent dense-cache study failed its TPU speed criterion. The fixed student's previous real-KataGo strength test also failed. This cache-layout study can establish an execution improvement only; MCTS integration, learning, strength and production recovery remain separate requirements.
