This is the first trainable control: a recipe-owned residual CNN with group normalization, policy/value heads, explicit momentum SGD, terminal-game replay and native PUCT self-play. It is an AlphaZero-style control, not an exact reproduction of AlphaZero, Leela Zero or KataGo. Group normalization, current observation planes, constant learning rate, lack of tree reuse, small fixed search budgets and replay scheduling are explicit choices to ablate later.

Clone this directory with `gozero clone research/recipes/az_reference <name>`. Its model, optimizer, loss, sampler and trainer remain local. `config.py` rejects missing/unknown scientific fields. `smoke.json` is a tiny CPU recovery qualification; `pod_smoke.json` exercises all configured hosts and the configured TPU devices. Neither configuration establishes playing strength.

Both paths use pure JAX with explicit data-parallel sharding. Parameters, momentum and augmentation RNG are replicated; inference and learner batches are partitioned. `games` and learner `batch_size` are per host. Actor identity and replay RNG use the discovered JAX rank, which can differ from the hostname suffix. All hosts retain a frozen network version for an entire real-move search. Replay is sampled uniformly per host, with equally weighted host contributions to each global learner batch; it is not uniform sampling from a single pooled replay store.

Inference combines model evaluation with a global active-slot count. An extra all-padding dispatch establishes global completion; completed local actors continue padding until every host is ready. Counts include that cost. This is a measurable synchronous control for later batching and speculative execution work. Python schedules coarse batches; every board transition, legality check, search backup, move sample, history plane and terminal outcome label runs in Rust. The current bridge transfers feature/replay buffer ownership to NumPy but still collates worker buffers and copies neural replies.

Checkpoints occur between committed real moves. They save parameters, momentum, augmentation RNG, each host's NumPy replay RNG, replay arrays/count/cursor, counters, unfinished games and actor RNGs. Rust replays saved moves to recover exact superko and observation history and regenerates unfinished-game features. A fresh process must use the same snapshot, native binary, configuration, world size and JAX rank's shard. The native layer permits worker-count changes, while this recipe requires the same full configuration for exact continuation.

Rank files are written, fsynced and atomically published with checksums. All hosts verify identical replicated learner state before publishing a group manifest. `--resume <rank-local checkpoint directory>` requires this group manifest. Incomplete directories and altered content are rejected. `--stop-after-turn` changes only a segment boundary, preserving the original scientific horizon. Failures before group publication leave uncommitted rank shards that are not automatically selected. Durable remote storage, retention, coordinated restart selection, fast peer cancellation and production recovery qualification remain separate work.

`model_export.npz` is an inference export. Training continuation uses the complete checkpoint directory. Reports retain compilation, inference, native, learner, checkpoint, process CPU and wall times. They do not call these counters MFU or claim improvement from falling training loss. The [JAX host-local array interface](https://docs.jax.dev/en/latest/_autosummary/jax.experimental.multihost_utils.global_array_to_host_local_array.html) defines the boundary used to return predictions to the native actors.
