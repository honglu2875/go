This recipe trains a causal action-history transformer with separate expert, value and observed-behavior objectives. Model, losses, AdamW, sampling and the full training loop live here; shared archival, checkpoint and batch utilities are importable from `gozero`. It uses JAX and NumPy without Flax or Optax.

Each prediction at ply t receives BOS followed by actions strictly before t. MCTS distributions and terminal side-to-move outcomes train the expert trunk/heads. Independently sampled observed actions train the behavior head, with stopped gradients at the shared trunk. Capped games contribute behavior observations and never outcome targets. The model receives no teacher identity, network version, future move or outcome as input.

`dataset.json` pins 16 final replay/archive pairs from the two Gumbel CNN and two attention runs. `ops/prepare_sequence_data.py` verifies complete archives, joins exact per-ply actions/network versions, excludes overwritten replay prefixes, and publishes packed arrays atomically. The dataset contains 1,047,681 expert rows and 798,969 observed-move rows; 25 sampled behavior games reached the move cap. Whole-game 80/10/10 splits are shared by both populations. Held-out episodes may contain positions/sequences also seen in other episodes.

`cpu_smoke.json` and `tpu_qualification.json` qualify the complete sampler/Adam/checkpoint continuation. `pilot_41.json` is the fixed 4,096-update feasibility pilot: four layers, width128, four heads, 890,240 parameters, bfloat16 matmuls, 16 games per objective per host, and global data parallelism over16 TPU chips. AdamW uses lr3e-4,128-step warmup, cosine decay to10%, beta(.9,.95), epsilon1e-8, matrix-only weight decay.01 and gradient clip1. All three losses have unit coefficient and their own token denominator.

Training requires the pinned dataset directory on each host. Freeze the recipe with `python -m gozero snapshot research/recipes/causal_distillation --config research/recipes/causal_distillation/pilot_41.json`; launch the frozen `ops/pod_run.py` with an explicit `--workspace-root`, snapshot, execution timeout and preparation timeout. The recipe does not require a native build for supervised training. `--resume` selects a committed checkpoint directory; `qualify_recovery.py` audits every parameter/Adam array and non-timing scientific field.

The inherited `probe.py` remains an untrained CPU execution probe for the paired2N-ply/k-sample decoder, with exact Rust legality and causal branch resolution. It does not load the student export. Its small configs are `cpu.json` and `cpu_root_mask.json`; its entry point is separate from the learner. `test_model.py` retains causal/KV/sampler checks with the new loss interface.

See `research/studies/causal_distillation` for frozen protocols, recovery receipts and pilot results. Prediction losses are not playing strength, learned opponent-level calibration or a multi-step throughput result. The next experiment must load learned weights into the paired execution harness, compare the same real action streams, measure wasted branches and returned bytes, and address the remaining illegal probability before integration with MCTS and real KataGo evaluation.
