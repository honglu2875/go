This clone isolates inference synchronization from the `az_reference` control. It owns a complete copy of model, loss, optimizer, configuration and trainer code. Learning behavior is held fixed; the inference executable uses each host's local four-device mesh and a local completion condition.

Global parameter replicas are viewed on local devices without copying the weights through CPU memory. Native actors retain a fixed model version for each root search. Local groups can complete different numbers of neural batches; hosts rendezvous for global learning, replay readiness and checkpoint publication. There is no cross-host reduction or final all-padding completion dispatch inside search inference. Per-example group normalization keeps padding from changing active predictions.

The registered 9×9 systems study measured a median 1.40× complete training speedup and 2.03× inference speedup in three interleaved pairs. Every saved learning array, actor state and game artifact matched the baseline. Read the [study](../../studies/local_inference/README.md) for frozen identities, timings and limits. This is a systems improvement; it is not speculative search, an architecture improvement or a sample-efficiency claim.

The full checkpoint format and scientific schedule are inherited as copied code. The baseline passed exact fresh-process CPU and multi-host TPU continuation. This recipe's own recovery/fault-injection qualification remains required before promotion. It also retains the baseline's raw Tromp–Taylor scoring contract, small search budget, simple replay schedule, and limited CPU isolation.
