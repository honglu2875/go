# State expert with a fixed observed-opponent predictor

This clone owns a complete resumable plain-JAX expert trainer, an unchanged history-model fixture, a spatial attention model, exact feature conversion, and qualification scripts. It compares `architecture=history` with `architecture=state`. Both optimize the same expert policy cross entropy and terminal-outcome MSE from the same verified internal-teacher dataset. The behavior predictor is the same separately pinned original exact-board checkpoint in both arms. Its weights are validated but are not optimizer parameters, training targets or checkpoint arrays in this experiment.

The history control removes only the unused behavior parameters from its trainable tree. Its expert predictions, expert-only loss and expert gradients must agree with the owned original model when the behavior objective is masked out. This is a fresh expert-only control: removing the old behavior gradients also removes their contribution to the global clipping norm, so it is not the previous joint-training run and cannot reuse that run as its matched control. The same AdamW schedule and clipping convention apply to both new arms. Training a new history encoder for opponent prediction is a later, separate experiment.

The state expert uses a pointwise stem, pre-normalized global attention, a four-times-width MLP, D4-tied relative-distance biases, and point-policy/pass/value heads. Mean and maximum spatial pooling inform pass and value prediction. Inputs are relative own/opponent/empty stones, exact point legality, previous-pass context, player color, signed komi, edge distance and board size. Current targets and future states never enter earlier inputs. Rust remains authoritative for legal moves, captures, repetition and terminal scoring; these inputs are not a claim of complete Markov state under superko.

`state_features.py` defines the feature contract for both recorded expert positions and native pending leaves. `leaf_predictions` evaluates one requested board directly for the spatial expert and preserves full causal history for the control. The state architecture can reuse its parameter tree across board-size buckets up to its declared geometry limit; 19x19 arithmetic qualification is distinct from 19x19 training or strength. The history control remains tied to its action vocabulary and context.

Sampling and evaluation select only expert episodes. The existing behavior dataset and labels remain unchanged. Complete checkpoints retain expert parameters, Adam moments, exact sampler state, counters, source/config/data identities and all-rank manifests. The observer's separate descriptor and complete checkpoint lineage are pinned in the configuration and validated before and after training. Its prior training and teacher-generation costs remain in lineage.

`cpu_history.json` and `cpu_state.json` specify bounded eight-update recovery checks. The TPU qualification configurations use the intended full architectures for 16 updates. Pilot configurations are preparation, not a scientific registration or launch authorization on their own. Freeze the comparison, resource cap, exact checkpoints and fresh paired KataGo panel before full runs. Report actual trainable parameters, measured update/inference cost, padding and global expert exposures; keeping unused parameters would not count as matching capacity.

Qualification covers independent NumPy attention arithmetic, D4 transformations, same-weight 19x19 shapes, native captures/ko/passes, target isolation, control-gradient agreement, and requested-leaf parity. The new expert requires its own model descriptor and GTP adapter qualification before benchmarking. It is not interchangeable with the existing board-causal three-head adapter. No new strength, RL sample-efficiency, MFU or production claim is made by the implementation alone.

The completed [registered study](../../studies/state_expert_distillation/README.md) passed CPU/GTP/multi-host recovery and audited all 144 scheduled real-KataGo games, but failed both scientific screens. Spatial value error improved while policy imitation and game completion regressed. Preserve this clone as a qualified research component; its current spatial configuration is not a production choice. The owned training/external/registration auditors and artifact index retain the negative result and initial GTP qualification repair.
