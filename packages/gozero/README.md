`gozero` is the importable shared library. It implements recipe cloning, content-addressed source/config snapshots, host-manifest/SSH command construction, attested coarse native bindings, atomic checksummed local checkpoints, an independent validation-only area scorer, and numbered GTP subprocess transport with deadlines and retained transcripts. Scientific model and training code belongs in each cloneable research recipe and, after promotion, in the corresponding production recipe.

Further shared capabilities include speculative packet transport, durable replay/checkpoint storage, coordinated recovery, and larger evaluation panels. Keep imports lightweight: source-management commands do not initialize JAX or require an accelerator. NumPy imports are confined to numeric interfaces.
